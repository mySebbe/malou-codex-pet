# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| `1.x` | Yes |

## Reporting

This repository is primarily an asset package and should not require secrets to install or use.

Please open a GitHub issue for public, non-sensitive problems such as broken install instructions, corrupted assets, or wrong checksums.

Do not post secrets, tokens, passwords, private photos, private prompt logs, or personal data in issues or pull requests.

## Scope

The release package is intended to contain only:

- `pet.json`
- `spritesheet.webp`
- public preview assets
- sanitized metadata and documentation

Any file containing local Codex state, prompt history, access tokens, passwords, or machine-specific private paths is out of scope and should not be committed.
